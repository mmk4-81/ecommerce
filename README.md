# Laravel Ecommerce Project

This project was a **university assignment** developed with the **Laravel framework**.  
The main idea was to build an online clothing store.  

## Project Status
The project was not completed to a production-ready level.  
However, a functional prototype was implemented and used for the course submission, which was sufficient to receive the required grade.  

## Technologies Used
- PHP 8.x  
- Laravel 11.x  
- MySQL  
- Vite + React (for the frontend)  

## Notes
- This project was developed **for educational purposes only**.  
- It can serve as a starting point for building a more complete ecommerce application in the future.
